## About

Ceiba Labs is a software studio dedicated to building technology that makes everyday life a little better.

We believe the best products are not the ones with the most features, but the ones that solve real problems with simplicity, care, and thoughtful design.

Everything we build follows the same principles:

- ⚡ Simple by design
- 🔒 Privacy-conscious
- 🛠️ Built to last
- ❤️ Crafted with care
