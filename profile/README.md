# Ceiba Labs

We build technology that helps people grow.

Ceiba Labs is a software studio creating thoughtful digital products for
people, families, and creators. We focus on software that is useful, reliable,
and designed to serve people for the long term.

## What we build

- **Lentri.nl** — Thoughtful technology for everyday life.
- **Family Compass** — Simple digital tools that help families stay connected.
- **Open source** — Reusable tools, libraries, and experiments for the developer
  community.

## Principles

- Human first
- Simple by design
- Privacy conscious
- Built to last
- Crafted with care

> Technology should support people, not distract them.
